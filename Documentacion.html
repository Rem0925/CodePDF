Aprende a dominar el motor de renderizado CodePDF para crear documentos académicos y profesionales con formato APA estructural.

# Introducción

El Generador de Documentos PDF es una herramienta avanzada que te permite crear documentos estructurados a través de un editor de código ligero. Utiliza un sistema de marcado (tags) personalizado que el motor traduce instantáneamente a un PDF con formato estándar (márgenes, tipografía Times, sangrías APA, etc.).

Todo documento comienza abrazando el contenido con etiquetas. Toda etiqueta se abre con @nombre@ y se cierra con @/nombre@.

# Etiquetas de Jerarquía (Texto)

Etiqueta Formato Aplicado (APA) Uso en Índice
@Resumen@ Al igual que Introducción y Conclusión, aparta una hoja para situar el resumen (Abstract) de tu trabajo. A diferencia de las demás, este carece totalmente de sangrías. @Resumen@
@titulo1@ Centrado, Negrita. Nivel 1 (Principal)
@titulo2@ Alineado a la Izquierda, Negrita. Nivel 2 (Con sangría)
@titulo3@ Alineado Izquierda, Negrita y Cursiva. Nivel 2
@titulo4@ Con Sangría de párrafo, Negrita. (Añade punto final) Nivel 3
@parr@ Fuente normal, alineación izquierda con sangría en la primera línea. No se incluye
@citaLarga@ Sangría de bloque (Hacia la derecha) de 1.27 cm (0.5 in) en todas las líneas. Para citas de +40 palabras según formato APA. No se incluye
@referencias@ Genera Sangría Francesa obligatoria para bibliografía. Cada cita dentro de esta etiqueta sangrará sus siguientes líneas automáticamente. Usar al final del documento
@lista@ Crea una lista de viñetas. Para separar cada elemento de otra viñeta utilza el separador -|. No se incluye
@notaPie@ Genera una línea divisoria y un número de referencia (¹) en un tamaño de letra reducido para anotaciones breves. No se incluye

text_format Etiquetas Internas (Sub-Formatos)

Sintaxis Descripción Ejemplo de Uso
**texto** Convierte cualquier bloque de palabras dentro de un párrafo en letra Negrita (Bold) estructural. El **texto** libre
*texto* Convierte la oración adjunta en Cursiva (Italic) directamente. Compatible con alineaciones. El *texto* libre

# Etiquetas de Estructura (Funciones)

@Portada@ ... @/Portada@

Genera una hoja de presentación. Usa -| para separar líneas. Los primeros 2 elementos se centran arriba, el resto se alinea a la derecha abajo.

@Indice@ ... @/Indice@

Autogenera la tabla de contenidos recolectando los títulos y asignando los números de página. Salta de página al terminar.

@Introduccion@ / @Conclusion@

Generan el título principal automáticamente, configuran el espaciado correcto y fuerzan un salto de página al terminar.

@pagebreak@

Fuerza manualmente un salto a la siguiente página del PDF.

# El Menú de Autocompletado

Para agilizar la escritura, el editor incluye un menú flotante predictivo.

  • Escribe un guion - en cualquier parte del editor.
  • Comienza a escribir el nombre de la etiqueta (ej. -por para Portada).
  • Haz clic en la sugerencia. El editor insertará automáticamente las etiquetas de apertura y cierre y colocará el cursor dentro.

Usa el atajo -Lorem para insertar texto de relleno aleatorio al instante y probar el diseño visual de tus páginas.

# Solución de Problemas Frecuentes

El PDF se genera en blanco o da error

Verifica que TODAS tus etiquetas estén cerradas. Si abres un @parr@ y olvidas poner el @/parr@ al final, el procesador fallará al calcular los bloques de texto.

Los títulos no aparecen en el Índice

Asegúrate de que estás usando etiquetas exactas de jerarquía de títulos (@titulo1@, @titulo2@). Si usas negritas manuales en un párrafo normal, el sistema de índice no lo detectará.

He perdido mi información

El editor guarda tu código automáticamente en el navegador usando localStorage. Sin embargo, si borras la caché o usas modo incógnito, se perderá. Usa el botón "Descargar Código Fuente" de la barra lateral para hacer backups físicos en tu PC (.txt).
